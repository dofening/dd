# Folia 歌词（手机 / 平板版）

跟随 Spotify 播放的歌词动画，在 iPad、iPhone 和安卓设备上独立运行，不需要电脑。

- 打开：<https://dofening.github.io/dd/>
- iPad / iPhone：用 Safari 打开上面的网址 → 分享 → “添加到主屏幕”，之后从主屏幕全屏打开。
- iPad：进入后点右上角全屏按钮申请隐藏系统状态栏；主屏幕启动本身不等于完整全屏，是否允许由 iPadOS 决定。
- 轻点画面隐藏／呼出按键，双击播放／暂停；横滑调进度，左侧竖滑调本页亮度，右侧竖滑调 Spotify 音量，进度和音量松手才提交。播放设备不支持远程音量时请用设备音量键。
- 支持横屏、竖屏和分屏；离线缓存会检查新版。更新后首次请联网打开，必要时完全关闭主屏幕应用再打开。
- 「显示设置 → HDR 高光」保留原动画。经典、云阶、倾斜、墨染、直书和星轨会点亮唱到的歌词笔画。花火在支持 WebGPU HDR 输出的设备上增强烟花与场景辉光的亮部。其他动画和不兼容的显示环境继续使用原高亮。
- 登录 Spotify 后，在任意设备的 Spotify 里播放歌曲，歌词会自动跟随；控制播放需要 Spotify Premium。
- 账号凭据、歌词缓存和设置只保存在你自己的设备上，本网站没有后台服务。
- 歌词来自 LRCLIB，繁体自动转为简体（日文歌词保持原样）。
